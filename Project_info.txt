FARMER ADVISORY SYSTEM — PROJECT INFORMATION
================================================

Last Updated: April 2026

========================================================
1. PROJECT OVERVIEW
========================================================

The Farmer Advisory System (AgriAssist) is a comprehensive
microservices platform designed for farmers across India.
It provides intelligent, real-time agricultural 
recommendations through a modern web interface supporting
English (Default), Hindi, and Marathi languages.

The system integrates high-accuracy ML models, live weather
APIs, and rapid-inference LLMs (Groq & Gemini) to provide
end-to-end farming advisory — from crop selection and
fertilizer dosing to smart irrigation and risk alerts.

========================================================

========================================================
5. SERVICES DETAIL
========================================================

SERVICE 1: Frontend (App/)
  Port    : 9002
  Tech    : Next.js 15, React, Tailwind, shadcn/ui
  Role    : Main user interface.
  Features:
    - Multi-language Dropdown (English, Hindi, Marathi)
    - Native regional text with zero language mixing.
    - Responsive dark/light modes.
    - Graceful offline fallback windows.

SERVICE 2: Main API (backend/)
  Port    : 5009
  Tech    : Flask, PostgreSQL, Twilio
  Role    : Authentication, farmer profiles, DB management.
  Features:
    - Auto-creates 'agriassist' database on startup.
    - Real SMS OTP via Twilio with 6-digit verification.
    - Indian phone number normalization (+91).
  Routes  :
    POST /auth/signup        — Register farmer
    POST /auth/send-otp      — Send Real/Demo SMS OTP
    POST /auth/verify-otp    — Verify 6-digit OTP
    POST /profile/save       — Save farm profile
    GET  /profile/<id>       — Get farmer profile

SERVICE 3: AgriAssist AI Chat (chat/)
  Port    : 5005
  Tech    : Flask, Groq SDK, LLaMA-3.3-70B
  Role    : National AI agriculture assistant.
  Features:
    - India-wide context (All crops, All states).
    - Sub-second response time.

SERVICE 4: Crop Recommendation (crop/)
  Port    : 5001
  Model   : Random Forest (300 trees, balanced weights)
  Data    : ~5000+ rows combined (smart_crop_data + extras)
  Features:
    - Returns Top-5 crop recommendations with probabilities.
    - Fetches live temperature & rain from Open-Meteo.
    - Covers 5 Maharashtra districts.

SERVICE 5: Fertilizer Advisory (fert/)
  Port    : 5002
  Model   : Random Forest (300 trees, balanced weights)
  Data    : ~5000+ rows (fertilizer_data + extras)
  Features:
    - Returns Top-5 fertilizer recommendations.
    - Includes newer fertilizers: 19:19:19 NPK, 20:20:0:13,
      Ammonium Sulphate, MOP, DAP, Urea.
    - Supports Moong crop type (newly added).

SERVICE 6: Weather Forecast (weather/)
  Port    : 5003
  API     : Open-Meteo (current + 7-day forecast)
  Role    : Provides:
    (a) Live weather: temperature, humidity, wind
    (b) 7-day forecast incl. precipitation_sum (rainfall)
    (c) AI irrigation advice (from irrigation_model_v2.pkl)
  Note    : The Weather service already returns ACTUAL
            rainfall data (current + 7-day forecast) from
            Open-Meteo. NO separate rainfall prediction ML
            model is needed — Open-Meteo provides daily
            precipitation forecasts directly.

SERVICE 7: Smart Irrigation (Irrigation/)
  Port    : 5006
  Tech    : Flask, Google Gemini AI
  Role    : AI-powered irrigation scheduling advice.

SERVICE 8: Live Alert System (Alert/)
  Port    : 5010
  Tech    : Flask
  Role    : Rule-based weather risk alerts.

8. KEY DESIGN DECISIONS
========================================================

1. NATIONAL SCOPE: Context broadened from state-specific to 
   all-India coverage to serve the entire farming community.

2. REAL SMS VERIFICATION: Integrated Twilio for production-grade
   6-digit OTP security on mobile devices.

3. ENGLISH BY DEFAULT: Set as the common link language, with
   instantly accessible localized options via a dropdown.

4. AUTO-DATABASE INFRA: Backend now checks and creates the 
   PostgreSQL database automatically to ensure zero-config startup.

5. DARK MODE FRIENDLY: UI elements (inputs, cards) optimized for 
   perfect visibility in both light and dark themes.

6. OPEN-METEO FOR RAINFALL: Instead of training a custom rainfall
   prediction model, the system uses Open-Meteo's native 7-day
   precipitation forecast — more accurate, always up-to-date.

7. BALANCED ML TRAINING: Both crop and fertilizer models use
   class_weight='balanced' to handle any class imbalance in
   the training data, improving minority class accuracy.
